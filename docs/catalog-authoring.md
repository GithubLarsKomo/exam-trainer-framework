# Catalog authoring

1. Use stable card IDs.
2. Use one card per numbered subtask.
3. Provide one or two variants where useful.
4. Preserve source terminology.
5. Record filename, PDF page, printed page, chapter, section, and exam question where available.
6. Mark uncertainty with `needs_review`.
7. Validate the JSON catalog.
8. Review by chapter.
9. Release only manually verified cards.
10. Treat question, model-answer, or required-term changes as material changes that reset learner progress.
